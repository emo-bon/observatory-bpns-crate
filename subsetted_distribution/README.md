# EMO BON Subsetted Distribution: BPNS (bluecloud-ENA)

- **Date Published**: 2026-10-19
- **Observatory Station**: BPNS
- **Affix / Purpose**: bluecloud-ENA (Sequenced samples with ENA run accessions)
- **Specification Conformance**: RO-Crate 1.2
- **License**: Creative Commons Attribution 4.0 International (CC BY 4.0)

## Citation
European Marine Biological Research Centre (EMBRC), European Marine Omics Biodiversity Observation Network (EMO BON), Metadata logsheets for Marine genomic sampling metadata from EMO BON Observation Network [station EMOBON-BE; Belgium], 2026, https://data.emobon.embrc.eu/observatory-bpns-crate/, emobon@embrc.eu

## Contents
- `ro-crate-metadata.json`: RO-Crate 1.2 catalog metadata descriptor.
- `logsheets/`: Sampling, measured, and observatory logsheet CSVs filtered for qualifying events.
- `all-triples.ttl`: Subsetted RDF semantic graph for all matching events, samples, and observations.
- `ena_accessions_subset.csv`: Mapping table of sampling events, sample IDs, and ENA run accessions.
